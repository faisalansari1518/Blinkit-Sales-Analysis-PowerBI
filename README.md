# 🛒 Blinkit Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze Blinkit's sales performance, item categories, outlet types, and customer ratings.

The dashboard helps explore sales trends and compare the performance of different outlet locations and product categories.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Compare sales across outlet location tiers.
- Identify top-performing item categories.
- Analyze sales by fat content.
- Evaluate outlet performance using key business metrics.
- Monitor average customer ratings and item visibility.

## 🔍 Key Dashboard Features

- **Sales Trends:** Year-wise sales analysis.
- **Fat Content Analysis:** Comparison of Low Fat and Regular products.
- **Item Type Analysis:** Sales distribution across product categories.
- **Outlet Analysis:** Comparison of Tier 1, Tier 2, and Tier 3 locations.
- **Outlet Type Comparison:** Analysis of sales, item counts, average sales, ratings, and item visibility.
- **Interactive Filters:** Filter results by outlet location type, outlet size, and item type.

## 💡 Business Value

This dashboard provides a consolidated view of sales performance and outlet-level metrics. It can help business users explore performance differences, identify areas for further investigation, and support data-driven decision-making.
